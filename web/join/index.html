VIGIL

Three steps

  1. Fork the repository and turn Actions on. Fork
  2. Open Actions, choose Join a room, type the room code, and press Run.
  3. Read the color. Green: the copies match. Yellow: not yet. Red: they disagree.

You type only the room code. The node makes its own key and does not show it. The key is not saved in the repository: GitHub's workflow token cannot store a new secret, and asking for another token would be a second question.

Solo escribes el código. El nodo crea su clave y no la muestra. La clave no se guarda en el repositorio.

On a computer: python3 scripts/swarm_join.py CODE

That command finishes in under 2 seconds. It does not ask another question.
