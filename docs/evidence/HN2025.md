# Honduras 2025 — evidence card

This is the only description of the bundled 2025 sample that grant text should repeat. Other pages link here.

## What is in the repository

- **64 JSON files** in `tests/fixtures/hnd_2025/`. They are public responses from Honduras' National Electoral Council (CNE) for the general election of 30 November 2025.
- **Filename timestamps** run from 2025-12-03 16:25 through 2025-12-10 17:03. The files were saved by hand across that span. They were not produced by the automated poller, and they were not all saved on a single day.
- **No `previous_hash`.** `python3 verify/verify_chain.py tests/fixtures/hnd_2025/` exits **1**, status `orphans`, **63** files after the first. That is the correct result. These files are not a hash chain.
- **Merkle root** of the 64 files, SHA-256: `f17dbfe188d2f1a1b31248a343ae3397984ef2ec6550bd1bcded03d31d2a7780`. `make replay-offline` recomputes it with no network. `tests/fixtures/hnd_2025/MERKLE_ROOT_HN2025.ots` is a commitment to that root. It shows those bytes existed in that form at attestation time. It is not continuous custody during the count.

## What the numbers are

| Observation | Value | How to read it |
|---|---|---|
| Stored files | 64 | Count of JSON files in the fixture directory |
| Longest interval with no stored file | 25.1 h (2025-12-09 16:00 → 2025-12-10 17:03) | Difference of filename timestamps. **Not** a measured portal outage. There is no fetch log. |
| Intervals longer than 10 h with no stored file | 7 | Same limitation. The operator note in the pilot report already says overnight holes match times when nobody was saving files. |
| Inconsistent-acta count, 2025-12-04 15:00 → 16:00 | 2,346 fewer | Delta between two stored files, 60 minutes apart |
| Rate | 39.15 per minute | That delta divided by 60 |
| Comparison | about 3.9× a **heuristic** of 10 per minute | `DEFAULT_MAX_RESOLUTION_RATE = 10` in `src/auditor/inconsistent_acts.py`. Not a measured human capacity. Not a pre-registered hypothesis for this sample. |

The threshold file `docs/research/THRESHOLD_PREREGISTRATION.md` says its numbers do **not** apply to this retrospective. The June 2026 hash recorded there no longer matches `command_center/rules.yaml`. Do not call 39.15 a pre-registered result.

A change of about −0.504 points in a leading share across one of those intervals is a difference between two stored aggregates. It is not, by itself, a significance test with a pre-declared contrast.

Small positive deltas while the inconsistent-acta count stays high are a description of the stored series. They are not evidence of intent.

## What was not measured

- Whether the portal answered, timed out, or was simply not requested.
- A chain of custody written while the count was open. The git history of this repository starts later.
- Polling-station records. The files are national aggregates.
- Calibration on any election other than this same series. Some comments in `command_center/rules.yaml` were fit on these 64 files. That is exploratory.
