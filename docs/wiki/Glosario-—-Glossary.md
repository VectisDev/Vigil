Términos que aparecen en VIGIL y su documentación · Terms used across VIGIL and its documentation.

| Español | English | Significado · Meaning |
|---|---|---|
| Acta | Tally sheet | Documento con el resultado de una mesa de votación · Record of one polling table's result |
| Acta inconsistente | Inconsistent tally sheet | Acta con errores aritméticos o de registro que pasa a escrutinio especial · Sheet with arithmetic or record errors sent to special scrutiny |
| Anclaje | Anchoring | Registro de un hash en Bitcoin para probar que existía en una fecha · Recording a hash on Bitcoin to prove it existed at a date |
| Apagón de comunicación | Communication blackout | Periodo en que la autoridad deja de publicar datos · Period in which the authority stops publishing data |
| Cadena de hashes | Hash chain | Secuencia en la que cada captura incluye el hash de la anterior · Sequence where each capture includes the previous one's hash |
| Captura (snapshot) | Snapshot | Copia de los datos oficiales en un momento dado · Copy of the official data at a given moment |
| Escrutinio especial | Special scrutiny | Revisión de actas inconsistentes por la autoridad · The authority's review of inconsistent sheets |
| Federación / enjambre | Federation / swarm | Conjunto de nodos que comparten capturas firmadas sin coordinador · Nodes sharing signed captures with no coordinator |
| Gossip | Gossip protocol | Forma en que los nodos se pasan capturas entre sí · How nodes pass captures to each other |
| Hash (SHA-256) | Hash (SHA-256) | Huella digital única de un archivo; cualquier cambio la altera · A file's unique fingerprint; any change alters it |
| Ley de Benford | Benford's law | Distribución esperada de los primeros dígitos en muchos conjuntos de datos · Expected distribution of leading digits in many datasets |
| Mesa (JRV) | Polling table | Unidad donde se vota y se cuenta · Unit where votes are cast and counted |
| Nodo / testigo | Node / witness | Instancia de VIGIL que captura y verifica de forma independiente · A VIGIL instance capturing and verifying independently |
| OpenTimestamps (OTS) | OpenTimestamps (OTS) | Servicio gratuito para anclar hashes a Bitcoin · Free service for anchoring hashes to Bitcoin |
| Padrón | Voter roll | Lista de personas habilitadas para votar · List of people eligible to vote |
| Participación | Turnout | Votos emitidos sobre personas inscritas · Ballots cast over registered voters |
| Raíz de Merkle | Merkle root | Hash único que resume muchas capturas · Single hash summarizing many captures |
| Regla | Rule | Prueba estadística o aritmética que señala una anomalía · Statistical or arithmetic test that flags an anomaly |
| Z-score | Z-score | Cuántas desviaciones estándar se aleja un valor de lo normal · How many standard deviations a value is from normal |
