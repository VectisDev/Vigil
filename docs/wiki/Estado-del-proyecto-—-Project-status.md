## Español

**Versión 0.1 — previa al piloto en vivo.** El núcleo criptográfico es estable; el siguiente hito es operar una captura continua en una elección real.

### Estado de validación

| Eje | Estado |
|---|---|
| Garantías criptográficas (T1–T4) | Completas y verificables en el código |
| Pruebas automatizadas | Se ejecutan en cada cambio (Python 3.11 y 3.12), junto con CodeQL, análisis de calidad y Dependabot |
| Piloto forense retroactivo | Completado: 64 archivos oficiales de Honduras 2025 ([detalle](Piloto-Honduras-2025-—-Honduras-2025-pilot)) |
| Análisis de falsos positivos | 500 ejecuciones, [resultados publicados](https://github.com/VectisDev/Vigil/blob/main/docs/research/FALSE_POSITIVE_ANALYSIS.md) |
| Convenciones estadísticas | Unificadas en un [documento de referencia](https://github.com/VectisDev/Vigil/blob/main/docs/stats/STATISTICAL_CONVENTIONS.md) |
| Validación académica independiente | Iniciada con la Universidad Pedagógica Nacional Francisco Morazán (UPNFM) |
| Piloto en vivo | Pendiente: previsto en una elección intermedia de 2026–2027, antes de Honduras 2029 |

### Hoja de ruta

1. **Verificabilidad pública** — que cualquiera pueda verificar sin instalar nada.
2. **Refuerzo criptográfico.**
3. **Núcleo estable separado de las reglas experimentales.**
4. **Resiliencia demostrable** bajo fallos y ataques.
5. **Gobernanza y cadena de suministro del software.**
6. **Métricas de precisión auditables por terceros.**
7. **Endurecimiento de seguridad para producción.**

Detalle de cada fase: [hoja de ruta](https://github.com/VectisDev/Vigil/blob/main/docs/grants/ROADMAP.md) · Historial de cambios: [CHANGELOG](https://github.com/VectisDev/Vigil/blob/main/CHANGELOG.md)

## English

**Version 0.1 — before the live pilot.** The cryptographic core is stable; the next milestone is running continuous capture during a real election.

### Validation status

| Axis | Status |
|---|---|
| Cryptographic guarantees (T1–T4) | Complete and verifiable in the code |
| Automated tests | Run on every change (Python 3.11 and 3.12), together with CodeQL, code quality analysis and Dependabot |
| Retroactive forensic pilot | Completed: 64 official Honduras 2025 files ([details](Piloto-Honduras-2025-—-Honduras-2025-pilot)) |
| False positive analysis | 500 runs, [results published](https://github.com/VectisDev/Vigil/blob/main/docs/research/FALSE_POSITIVE_ANALYSIS.md) |
| Statistical conventions | Unified in a [reference document](https://github.com/VectisDev/Vigil/blob/main/docs/stats/STATISTICAL_CONVENTIONS.md) |
| Independent academic validation | Started with the Universidad Pedagógica Nacional Francisco Morazán (UPNFM) |
| Live pilot | Pending: planned for an intermediate election in 2026–2027, ahead of Honduras 2029 |

### Roadmap

1. **Public verifiability** — anyone can verify without installing anything.
2. **Cryptographic hardening.**
3. **Stable core separated from experimental rules.**
4. **Demonstrable resilience** under failures and attacks.
5. **Governance and software supply chain.**
6. **Accuracy metrics third parties can audit.**
7. **Production security hardening.**
